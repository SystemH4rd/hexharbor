# HexHarbor 2.0 — початок роботи

Відкрийте https://systemh4rd.github.io/hexharbor/v2/ . Попередня синтетична демонстрація залишається за адресою https://systemh4rd.github.io/hexharbor/ . Код: https://github.com/SystemH4rd/hexharbor .

## Спробувати справжню перевірку

1. Email → «Перевірити example.org»: виконується живий запит DNS. Це домен прикладів, а не перевірка чиєїсь особистої скриньки. Картки показують реальні відповіді, джерело, час, TTL і межі.
2. Телефон → «Перевірити тестовий номер»: локальна бібліотека розбирає зарезервований тестовий номер. Власник та активність залишаються невідомими.
3. Фото → «Створити тестове PNG» або виберіть власне зображення. Розміри, байти, SHA-256 і підтримувані EXIF-теги обчислюються локально. Зображення не передається на сервер.
4. «Експорт JSON» завантажує звіт на ваш пристрій. Повні ідентифікатори приховані за замовчуванням; їх можна додати окремим прапорцем.

Мережеві помилки показуються як недоступні джерела. Вони не підміняються демонстраційними результатами. Дані телефону — правила плану нумерації, а не запит до поточного оператора.

## Запуск коду

Потрібні Node.js 22+, npm і Git:

```sh
git clone https://github.com/SystemH4rd/hexharbor.git
cd hexharbor
npm ci
npm run build
npm test
npm run check
npm start
```

Відкрийте http://localhost:4173/v2/ . Відкриття index.html через file:// не підходить для модулів. SHA-256 потребує HTTPS або довіреного браузером localhost.

## Публікація оновлень

Репозиторій і Pages уже існують. Створюйте гілку, вносьте зміни, перевіряйте pull request і зливайте його в main. Workflow встановлює залежності з lockfile, збирає локальні бібліотеки, перевіряє код та публікує docs/. Результат видно у вкладці Actions. Settings → Pages має залишатися Source: GitHub Actions; HTTPS увімкнений.

Не обирайте публікацію необробленої гілки: бібліотеки docs/v2/vendor/ генеруються під час збірки і не зберігаються в Git. Node API не запускається на Pages. Окремий API описаний у [API.md](API.md), джерела — у [SOURCES.md](SOURCES.md), архітектура — у [ARCHITECTURE.md](ARCHITECTURE.md).

scripts/publish.sh збережений як допоміжний сценарій початкового створення: він зупиняється, якщо SystemH4rd/hexharbor уже існує. Для поточних оновлень він не потрібен.
